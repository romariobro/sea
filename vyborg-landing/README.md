# Выборгские шхеры — самостоятельный лендинг

Вся страница находится в этой папке. Можно перенести или загрузить папку целиком.
Никакая сборка, Node.js, Next.js, папка Ladoga или файлы родительского проекта для работы не нужны.

## Открыть

Откройте `index.html` двойным щелчком. Для просмотра через HTTP из этой папки:
`python -m http.server 8767 --bind 127.0.0.1`
Адрес: http://127.0.0.1:8767/

## Состав

- `index.html` — все разделы страницы и тексты.
- `styles.css` — оформление и адаптивная вёрстка.
- `script.js` — увеличение изображений, переключение стрелками и закрытие Escape.
- `assets/photos/` — 21 фото катамарана в WebP.
- `assets/maps/` — 7 карт и 6 изображений координат из переписки.
- `assets/videos/` — 3 MP4 в плеерах и исходное видео MOV для скачивания.
- `assets/fonts/` — локальные шрифты; Google Fonts при просмотре не вызывается.
